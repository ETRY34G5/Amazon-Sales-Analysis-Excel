# Amazon Sales Analysis Dashboard using Microsoft Excel

## Project Overview
This project focuses on analyzing Amazon sales data using Microsoft Excel to understand sales performance, identify trends, and generate meaningful business insights.

An interactive dashboard was developed to present key sales metrics and performance indicators through charts, Pivot Tables, and visualizations.

## Project Objectives
- Analyze overall sales performance.
- Identify sales trends and patterns.
- Summarize business data using Pivot Tables.
- Track important Key Performance Indicators (KPIs).
- Present data insights through an interactive dashboard.

## Key Tasks Performed

### 1. Data Cleaning
- Organized raw sales data.
- Checked and handled data inconsistencies.
- Prepared data for analysis.

### 2. Data Analysis
- Used Pivot Tables for data summarization.
- Applied XLOOKUP to retrieve relevant information.
- Used Excel formulas for calculations.
- Analyzed sales-related information.

### 3. Data Visualization
- Created charts and graphs.
- Designed a dashboard to present key metrics.
- Used visual elements to make data easier to understand.
